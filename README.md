Blur-aware image enhancement with deep learning

🩺 MAACS
Maternal Assistive AI Care System

An AI-assisted fetal ultrasound analysis system designed to support investigation of IUGR, microcephaly, and hydrocephalus by combining computer vision, deep learning, and clinical measurements.

Highlights
- Fetal plane detection and image analysis
- Biometric measurements, including HC, AC, and LVW
- Gestational-age-aware predictions
- Graph Attention for label relationships
- Grad-CAM++ explainability and MC Dropout uncertainty estimation
Explore the project →

<sub>Research prototype; not a substitute for professional clinical diagnosis.</sub>

🤖 Multi-Agent Mock Interview Coach
Adaptive interview practice with execution-backed coding feedback

A multi-agent interview preparation app that adapts practice to a candidate's weaker topics, sources company- and role-relevant questions, and evaluates coding solutions by running them in a sandbox.

Highlights
- LangGraph agents for planning, interviewing, and evaluation
- Adaptive topic and difficulty selection
- Resume-aware and company-aware questions
- Code execution through Judge0 with deterministic pass/fail checks
- Separate communication feedback for spoken answers
- Streamlit UI plus a terminal interface
Stack: Python · LangGraph · Groq · Tavily · Codeforces API · Judge0 · Streamlit · SQLite
